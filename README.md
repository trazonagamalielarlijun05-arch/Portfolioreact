# Arli Trazona — Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev
Open http://localhost:5173/portfolioupgrade/

## Deploy to GitHub Pages
    git init
    git add .
    git commit -m "React portfolio"
    git remote add origin https://github.com/trazonagamalielarlijun05-arch/portfolioupgrade.git
    npm run deploy
Then: repo Settings -> Pages -> Deploy from a branch -> gh-pages / (root).
`base` in vite.config.js must equal the repo name.

## Edit content
Text, skills, projects and links are in `src/data/portfolio.js`.
